# Security

Do not submit proprietary game data or personal information through issues.
Do not download unofficial builds claiming to be endorsed by this repository.
Use the project's [published Releases](https://github.com/killeiro/Speed-Racer-Native-Port/releases)
to identify downloads. Report the exact version and file hash when reporting a
problem. A checksum identifies a file; it is not a malware scan, security audit
or guarantee of safety. Source publication and automated test results likewise
do not establish an independent security review.
Report potentially sensitive vulnerabilities privately to the maintainer rather than including exploit details in a public issue.
