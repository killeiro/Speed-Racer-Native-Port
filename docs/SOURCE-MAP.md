# Source map and contribution workflow

The playable v0.1.0 and its source snapshot are separate versioned artifacts.
Use the `source-v0.1.0` tag for this baseline. The earlier `v0.1.0` tag is kept
unchanged; it originally pointed to the documentation-only repository.

## Where to start

| Area | Source | Relevant checks |
| --- | --- | --- |
| Windows launch, integrated data and settings | `host/speedracer_main.cpp`, `host/media_*`, `host/speedracer_graphics.hpp` | media import, data pack, lifecycle |
| Keyboard and controllers | `host/keyboard.*`, `host/controllers.*`, `host/window.cpp` | keyboard, controllers, SIO2 input |
| EE runtime and hardware ordering | `runtime/src/system.cpp`, `dispatch.cpp`, `dmac.cpp`, `vif.cpp` | runtime lifecycle, VIF, queue |
| SPU2/audio | `runtime/src/iop/spu2.cpp`, `host/audio_output.hpp` | SPU2 audio, audio output |
| VU execution and arithmetic | `runtime/src/vu_micro.cpp`, `runtime/include/ps2/vu_*` | VU continuation, Q-delay, normalization, local cache |
| Accepted Fuji prefix blocks | `native/vu-local/blocks`, adjacent `tests` | local-block differential checks |
| Native Vulkan GS | `native/gs_hw`, `scripts/audit/build_hw_gs.py` | four standalone GS tests and optional runtime GS tests |
| Compute GS | `runtime/src/gs/gpu` | scale, mip, feedback, setup/snapshot checks |
| Recompilers | `recomp` | continuation generator/fixtures |
| Accepted game translation units | `generated/speedracer` | hash/count manifests and full native build |

Start with [BUILDING.md](BUILDING.md). Compiling the host/runtime and generated
sources requires no ISO, ELF, personal save or game installation. For gameplay,
use an isolated copy of the integrated playable package as described there.

The hardware launcher uses the separate native Vulkan GS. Editing the compute
GS does not automatically change the renderer selected by the official launcher.
The bridge imports pinned PCSX2/kzgs components, rather than starting PCSX2.

## Generated sources

The snapshot includes the exact accepted EE/VU translation units, the additional
310 VU programs and accepted continuation sources. It also includes the 40 Fuji
local blocks and the differential fixture that was external to the old checkout.
These inputs are committed and buildable; they are not silently regenerated by
the build wrapper. Their bytes and manifests must remain consistent.

`eerecomp`, `vurecomp`, `scripts/compile_vu_extra.py`,
`scripts/compile_vu_continuations.py` and `native/vu-local/generate_local_blocks.cpp`
expose the translation tools. Exact regeneration from an ISO alone is not claimed:
the accepted coverage also came from discovered entry points and runtime VU
captures. Those historical raw capture sets are not included in this snapshot.
Use the pinned generated sources as the release build inputs. New coverage needs
its own inputs, hashes and validation; keep it separate from the accepted set.

## Proposed changes

1. Fork the repository and branch from the source tag or a later reviewed main.
2. Describe a concrete trigger and the resulting behavior before and after.
3. Build the affected targets and run the pertinent tests. For runtime changes,
   run the full applicable CTest configuration; renderer changes also need GS
   checks and a visual comparison of an appropriate scene.
4. Keep default High 3×, HUD filtering, FXAA, adaptive fullscreen and input
   behavior unless the change explicitly addresses one of them.
5. Include actual commands, toolchain/dependency versions and the scope of the
   evidence. Performance claims need comparable inputs/settings and before/after
   measurements. Automated tests do not certify every physical input device.
6. Open a focused PR with the issue, source changes and verification. Do not
   include personal saves, local paths, credentials, data packs or build caches.

The current follow-ups are reproducible controller compatibility, intermittent
audio categories/track transitions, pause cadence and isolated hitches. A source
publication does not mark those issues resolved or start a broad manual test
campaign.
