# Codex audit mission

Work against the actual, latest development source tree; this GitHub repository currently contains **documentation only**.

1. Inventory source modules, build targets, external dependencies and license provenance.
2. Identify how simulation ticks and render frames are scheduled; measure wall time against simulated time.
3. Profile VU1 work, GS render paths, shader dispatches, transfers, texture uploads and CPU/GPU sync.
4. Diagnose missing graphical features against PCSX2 reference, with reproducible screenshots and logs.
5. Propose minimal patches, test each, quantify impact and note regressions.
6. Produce an ordered implementation backlog with evidence and links to source files.

Do not upload an ISO, BIOS, game's commercial assets or recompiled proprietary program code. Do not publicly publish an executable until rights review has cleared it.
